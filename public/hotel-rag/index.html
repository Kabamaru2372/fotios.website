Hotel Knowledge Assistant

An AI-powered RAG pipeline that lets hotel staff query internal training documents in natural language, deployed on Azure with a single command.

View on GitHub LinkedIn

Tech stack

Azure OpenAI (GPT-4o), Azure AI Search, Azure Blob Storage, Azure Functions, Azure Container Instances, Terraform, Docker, FastAPI, ChromaDB, Python, RBAC, managed identities

Key features

Zero hardcoded credentials

All services authenticate via system-assigned managed identities and RBAC role assignments. No secrets in code.

Single-command deploy

One script provisions all Azure infrastructure via Terraform, builds and pushes the Docker image, and wires everything together.

Automated indexing

Upload a document and the Azure Function triggers immediately. No manual steps, no waiting.

Full observability

Application Insights and Log Analytics with 30-day retention. Every query and error is tracked.

Architecture

./data/ ──upload.sh──► Blob Storage ──Azure Function──► RAG Backend (ACI) │ │ AI Search Index ◄────────────────────────────┘ │ Chat Web App ◄──── hotel staff
